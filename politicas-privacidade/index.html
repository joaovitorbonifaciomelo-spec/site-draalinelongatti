Política de Privacidade

Esta política explica como este site trata informações de quem o visita. Ele é informativo e não pede dados pessoais para ser usado.

O que este site faz

  • Sem formulário

    Nenhuma página pede nem envia dados por formulário.

  • Sem cookies próprios

    O código do site não cria cookies.

  • Sem rastreamento no código

    Não há ferramenta de análise de visitas ou de publicidade no código do site.

  • Arquivos do próprio site

    Fontes, imagens e vídeos são servidos pelo próprio site.

  • Preferência na sessão

    Se a pessoa pausa o vídeo, o navegador guarda essa escolha só durante a sessão, no próprio aparelho.

  • Preferências do aparelho

    Reduzir movimento e economia de dados são lidos no aparelho para ajustar o vídeo. O código não envia essas informações.

  • Hospedagem

    O site fica na Hostinger. Como em outros sites, o servidor pode registrar dados técnicos de acesso, como endereço IP, navegador, página visitada e horário.

Outros serviços

  • WhatsApp, telefone e e-mail

    Abrem o aplicativo escolhido pela pessoa, somente ao clicar. O que for enviado por esses canais é usado para responder ao contato.

  • Google Maps

    O mapa é carregado do Google quando a seção de localização se aproxima da tela. A partir daí, o Google recebe dados de acesso e pode usar cookies, conforme as regras dele. A rota só abre ao clicar.

  • Site da clínica

    O link leva a um site separado, que tem regras próprias.
